## Long Project Pitch (2 minutes)

"CyberSphere AI v4.0 is a full-stack enterprise cyber defense platform I designed and built to demonstrate production-ready software engineering at scale. The platform unifies seven security capabilities — AI-powered threat analysis, threat intelligence across four providers, user behavior analytics, cloud security posture management, container security, security knowledge graphs, and automated incident response — into a single, cohesive system.

On the frontend, I built a React 18 application with Vite 5, implementing code splitting, a custom design system with WCAG 2.2 AA accessibility, and real-time updates via Socket.IO. The backend follows an MVC architecture with Express.js, featuring 28 Mongoose models, 16 controllers, and comprehensive middleware for authentication, authorization, rate limiting, and input validation.

Security is central to the design. I implemented JWT with refresh token rotation, TOTP MFA with backup codes, RBAC, per-route rate limiting with Redis backing, and AI security guardrails including prompt injection detection and PII redaction. The platform is OWASP Top 10 compliant.

For AI, I built a multi-provider routing system that automatically selects between Google Gemini and Ollama based on query complexity, with graceful failover and security validation at each stage.

The infrastructure is containerized with Docker Compose (10 services) and deploys to Kubernetes with HPA auto-scaling, PodDisruptionBudgets, and NetworkPolicies. CI/CD runs automated tests — 419 total across Jest, Vitest, and Playwright — plus security scanning with Gitleaks, Trivy, and Semgrep.

Finally, I integrated full observability with OpenTelemetry distributed tracing, Prometheus metrics, and Grafana dashboards, ensuring the platform is not just functional but production-ready and maintainable."
